使用指南

路标帮你把「现在的你」和「想去的目标」之间的路拆成一条条可执行的路径。本指南介绍如何填写信息、读懂路径结果、启用 AI 生成，以及常见问题的解决办法。

1三种打开方式

根据你需要的功能选择打开方式

  • A
    双击 index.html（离线）不联网、不需要密钥，直接用本地知识库生成路径，适合快速体验。
  • B
    双击 start-server.bat（推荐）启动本地服务并自动打开浏览器，AI 生成功能可用，页面底部状态条会显示「AI 已就绪」。
  • C
    手动启动在命令行进入站点目录运行 python server.py，然后访问 http://127.0.0.1:8787。
直接双击 index.html 时 AI 不可用，属于正常现象；按方式 B 打开即可。

2填写当前状况

如实填写，路径里的达标要求会结合你的起点估算差距

  • 当前阶段：高中在读 / 高中毕业 / 本科在读 / 本科毕业 / 硕士在读 / 硕士毕业 / 职场人士。选择高中阶段会出现「高考分数」输入框。
  • 院校 / 单位、专业 / 方向：选填，填得越具体，起点摘要越清晰。
  • GPA：4.0 制，留学规划的重要参考。
  • 语言成绩：雅思 / 托福水平，系统会计算你与目标院校要求之间的差距。
  • 相关经历：实习、科研 / 项目、竞赛获奖、交换 / 海外经历、工作经历，可多选。
「暂不填写 / 不适用」也没关系，系统会按更保守的假设规划，并提示你补足的方向。

3填写目标

目标院校与目标职业都可以填，两者可组合，至少填写一项

目标院校（选填）

选择国家 / 地区后会出现对应院校下拉框，目前覆盖 61 所：美国、英国、新加坡、中国香港、澳大利亚、加拿大、中国、日本、欧盟 / 欧洲。每个院校都有 GPA、语言、GRE、费用与申请时间线等真实参考信息。

目标职业（选填）

可填目标公司（如 Google、博世、Shopee）+ 目标岗位（15 类，如软件工程师、量化研究员、游戏策划、机械 / 汽车工程师等）。

组合规则

  • 填写了目标职业：职业是路径终点；目标院校作为路径中的关键节点——填了院校就用你选的院校，没填则系统会推荐适配院校。
  • 只填写目标院校：院校就是路径终点，按留学路径规划。
  • 自定义目标（AI 专用）：知识库里没有的院校或岗位，用一句话写在这里（如「日本东京大学机器人学硕士」「米哈游战斗策划」），AI 会据此生成路径。
什么都不填就点生成，页面会提示「请至少填写一项目标」，不会空跑。

4时间与偏好

影响路径的排序与推荐标记

  • 距离关键时间点：还剩 1 年以内 / 1–2 年 / 2–3 年 / 3 年以上。
  • 可承担总预算：人民币口径，用于估算每条路径的花费档位。
  • 最看重什么：稳妥上岸（按成功率排序）、更快达成（按时长排序）、成本更低（按花费排序）、名校 / 名企牌子（保持多路径）。

两种生成方式的区别

对比项生成发展路径AI 生成路径

是否需要联网不需要需要启动本地服务并配置 DeepSeek 密钥

适用场景目标在知识库内、想快速稳定出结果知识库外的目标、想要更个性化的建议

结果页怎么看

  • 路径页签：顶部可切换 3–4 条不同路径。
  • 流程图节点：起点 → 关键节点 → 终点；点击节点可展开达标要求、所需材料、时间节点、风险提示。
  • 知识库 · 详情块：AI 结果中会附上「知识库 · 院校信息 / 岗位信息 / 公司时间线」等块，内容有据可查。
  • 路径对比表：总时长、花费、难度、成功率、适合人群横向对比。
  • 如果遇到意外：每条路径末尾附 Plan B 备选方案。

6启用 AI 生成

密钥只保存在你本机，通过本地服务转发，不会发送到浏览器

  • 1
    准备密钥在 platform.deepseek.com 的「API Keys」页面创建密钥。
  • 2
    配置 .env把 .env.example 复制为 .env，将 DEEPSEEK_API_KEY= 后替换为你的真实密钥并保存。
  • 3
    启动服务双击 start-server.bat，页面底部状态条显示「AI 已就绪 · 模型 …」后即可使用。

状态条可点击

保存或修改密钥后不需要重启服务：点击页面底部的状态文字「点击这里重新检测」即可生效；从结果页按「修改输入」返回时也会自动重新检测。

AI 结果基于公开常识推断，可能存在不准确之处，请以目标院校 / 公司官网最新信息为准。
不要在聊天或网页中粘贴密钥；密钥只在本地 .env 文件里使用。

7深色模式与打印

保持极简，只换配色

  • 点击右上角的月亮 / 太阳按钮切换深色与浅色模式，选择会被记住，默认跟随系统。
  • 支持浏览器打印 / 导出 PDF：打印时自动只保留规划结果，适合把路径保存成文档。

8常见问题

遇到问题先看这里

页面显示「AI 未配置」，但命令行显示已识别密钥？

说明有旧的服务窗口占着端口。关闭所有旧的黑色命令行窗口，重新双击 start-server.bat；新版服务遇到端口占用会明确报错提示。

保存密钥后页面还是显示未配置？

先确认打开的是服务地址（http://127.0.0.1:8787）而不是直接双击的 index.html；然后点击页面底部状态条「重新检测」，或按「修改输入」返回再回来。

端口 8787 被占用怎么办？

在 .env 中加一行 PORT=其他端口号 后重启；或关闭占用端口的程序。

AI 提示失败 / 返回内容为空？

服务会自动重试一次。仍失败时检查：网络（直连不通可在 .env 配置 AI_PROXY 指向本地代理）、DeepSeek 账户余额、密钥是否有效。

想换 AI 模型？

在 .env 中修改 AI_MODEL：默认 deepseek-v4-flash（快、省），需要更强推理可改 deepseek-v4-pro。

知识库里没有我想去的学校 / 岗位？

用「自定义目标」写一句话交给 AI 生成；也可以在 js/app.js 顶部的知识库部分自行追加院校、岗位与公司信息。

路标 · 升学与职业规划 —— 信息来自各院校 / 公司官网、教育部门与公开招聘信息等公开渠道，整理时间为 2026-08。

规划结果仅为参考建议，不构成录取或录用承诺。请以目标院校、考试官方与用人单位的现行政策为准。
