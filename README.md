# 路标 · 升学与职业规划

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

输入你的教育 / 职业现状与目标院校或目标岗位，自动生成 3 条以上不同的发展路径。每条路径是一条从「起点」到「终点」的流程图，每个节点都可以展开查看院校 / 岗位信息、达标要求、所需材料、建议时间与风险提示。

## 使用方法

- 直接双击打开 `index.html` 即可使用，无需安装任何软件、无需联网。
- 也可以在本目录启动一个本地静态服务后访问（任选其一）：
  - `python -m http.server 8080` 然后打开 `http://localhost:8080`
  - `npx serve .` 或任意静态文件服务器
- 环境要求：纯知识库功能无需任何环境；使用 AI 生成需要本机安装 **Python 3.10+**（Windows 一般已内置）。

页面顶部提供三个示例（高三 → 美国计算机本科 / 本科在读 → 牛津硕士 / 本科毕业 → 谷歌软件工程师），点击可快速体验。
站点内也内置了一份网页版使用指南（首页顶部「使用指南」按钮，或直接打开 `guide.html`），包含填写说明、AI 配置步骤与常见问题。

## 在其他设备上使用

本项目零依赖、跨平台，获取代码后即可运行：

1. 获取代码（任选其一）：
   - `git clone https://github.com/你的用户名/仓库名.git`
   - 或 GitHub 页面点 **Code → Download ZIP** 后解压。
2. **纯知识库模式**：直接双击打开 `index.html`，任何设备（Windows / macOS / Linux）都不需要安装环境。
3. **AI 模式**（需要 Python 3.10+ 与 DeepSeek 密钥）：
   - Windows：双击 `start-server.bat`；
   - macOS / Linux：命令行进入项目目录，运行 `python3 server.py`，然后浏览器打开 `http://127.0.0.1:8787`；
   - 每台设备把 `.env.example` 复制为 `.env` 并填入密钥（建议每台设备使用独立的 DeepSeek 密钥，便于单独撤销）。
4. **同步更新**：项目更新后，在本地目录执行 `git pull` 即可；知识库数据都在 `js/app.js` 中，更新即时生效。

## 启用 AI（可选，推荐）

AI 按钮可以生成知识库之外的目标（任意国家 / 院校 / 专业 / 公司 / 岗位）的发展路径。
密钥只保存在你本机，通过本地服务转发给 AI 接口，**不会发送到浏览器，也不会上传到任何网站**。

1. 把 `.env.example` 复制一份并改名为 `.env`（与 `server.py` 同一目录）；
2. 用记事本打开 `.env`，把 `DEEPSEEK_API_KEY=sk-把你的密钥粘贴到这里` 中的占位内容替换成你的真实密钥（在 platform.deepseek.com 的「API Keys」页面创建），保存；
3. 双击 `start-server.bat` 启动服务（或命令行运行 `python server.py`）；
4. 浏览器会自动打开 `http://127.0.0.1:8787`，页面上的「AI 生成路径」按钮变为可用。

说明：

- 服务只监听本机 `127.0.0.1`，其他人无法访问；
- 没有配置密钥时，「AI 生成路径」按钮会保持灰色并提示原因，知识库生成不受影响；
- 密钥保存后**无需重启服务**：在页面上点击底部状态文字「点击这里重新检测」，或按「修改输入」返回再回来，即可生效；
- 如果页面上一直显示未配置、而命令行显示已识别密钥：说明有旧的服务窗口占着端口。请关闭所有旧的黑色命令行窗口，重新双击 `start-server.bat`（新版服务遇到端口占用会明确报错提示）；
- AI 生成时会**自动调用本地知识库**：目标院校 / 岗位 / 公司在知识库内时，这些真实数据会注入 AI 提示词，并在返回路径的对应节点上附上「知识库 · 院校信息 / 岗位信息 / 公司时间线」等可展开详情块；知识库未覆盖的信息仍由 AI 基于常识补充（会提示以官网为准）；
- 想更换模型可在 `.env` 中修改 `AI_MODEL`：默认 `deepseek-v4-flash`（快、省），需要更强推理可改 `deepseek-v4-pro`；
- 如果直连 DeepSeek 不通，在 `.env` 中加一行 `AI_PROXY=http://127.0.0.1:7890`（改成你的代理地址；Clash 默认 7890）；
- 如果 8787 端口被占用，可在 `.env` 中加一行 `PORT=其他端口号`。

## 功能

- 现状输入：当前阶段、院校 / 单位、专业、高考分数、GPA、语言成绩、相关经历
- 目标输入：目标院校（选填，国家 / 地区、院校、专业）与目标职业（选填，公司、岗位）可同时填写
  - 填写了目标职业：职业是路径终点；目标院校作为路径中的关键节点（不填院校则系统会推荐适配院校）
  - 只填写目标院校：院校就是路径终点
- 自定义目标（AI 专用）：知识库外的院校 / 岗位，用一句话描述即可让 AI 生成路径
- 时间与偏好：距离关键时间点、预算、最看重的因素（稳妥 / 快速 / 成本 / 牌子）
- 输出：3–4 条发展路径，每条包含
  - 路径总览（难度、总时长、预估花费、成功率、适合人群）
  - 流程图节点：起点 → 关键节点 → 终点，节点可展开查看详细达标要求
  - 路径对比表与备选方案（Plan B）
- 两种生成方式：本地知识库生成（离线可用）与 AI 联网生成（需配置密钥）
- 深色模式：右上角月亮 / 太阳按钮一键切换，选择会记住，默认跟随系统
- 输入自动保存在浏览器本地，下次打开自动恢复
- 支持打印（浏览器打印 / 导出 PDF 时自动只保留规划结果）

## 数据说明

- 知识库覆盖 **61 所院校**（美国 / 英国 / 新加坡 / 中国香港 / 澳大利亚 / 加拿大 / 中国 / 日本 / 欧盟·欧洲）与 **15 类岗位**（软件工程师、产品经理、数据分析师、咨询顾问、投行分析师、人工智能工程师、交互 / UI 设计师、游戏策划、机械 / 汽车工程师、网络安全工程师、产品运营、量化研究员、生物医药研发、市场营销 / 品牌经理、人力资源），并包含 **36 家公司**的招聘时间线。
- 全部信息来自公开渠道（院校官网、教育部门、公司官网招聘页、公开招聘信息等），整理时间为 **2026-08**。
- 申请要求、语言分数、招聘时间等随时可能调整，**请以目标院校 / 公司官网最新公告为准**。页面内已内置免责提示。

## 文件结构

```text
index.html    页面结构（输入页 + 结果页）
guide.html    使用指南页（与站点同一设计语言，支持深色模式）
styles.css    设计规范与样式
js/app.js     全部前端代码：知识库数据 + 路径生成引擎 + 界面交互（已合并为一个文件）
server.py     本地 AI 服务（静态文件 + /api/ai-plan 接口，密钥只在本机）
.env.example  AI 密钥配置模板（复制为 .env 后填写）
start-server.bat  一键启动本地 AI 服务
```

## 扩展知识库

在 `js/app.js` 顶部的知识库部分（`KB` 对象）中：

- 新增院校：在 `KB.universities` 数组追加一条记录（参考现有字段），并在 `KB.countries` 中确认国家代码。
- 新增岗位：在 `KB.jobs` 追加岗位对象（参考 `swe` 的结构）。
- 新增公司时间线：在 `KB.companyNotes` 追加，并同步同文件 `companyNoteFor` 关键词表。
- 调整路径模板：在 `js/app.js` 中修改或新增 `buildXxx` 函数，并在 `generatePlan` 中挂载。
